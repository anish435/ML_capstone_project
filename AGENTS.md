# Repository Guidelines & Workflow

## Commit & Push Workflow
- Whenever the user asks to "push" or push changes to the repository:
  1. **Update `README.md`**: Always document recent changes, project overview, usage, or features before committing.
  2. **Stage & Commit**: Stage the modified files including `README.md` with a clear, descriptive commit message.
  3. **Push**: Push the committed changes to the configured remote repository branch.
